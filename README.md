# MARVEL 宇宙观影指挥中心

一个帮你**从零补全漫威宇宙**的本地网页系统:资料站 + 任务式观影清单 + 时间线 + 故事线地铁图 + 成就系统。

纯静态页面,零依赖、无需安装,所有进度保存在浏览器本地(localStorage)。

## 如何使用

任选其一:

- **直接打开**:双击 `index.html`(推荐 Chrome / Edge / Safari)。
- **本地服务**(任意静态服务器均可):

```bash
python3 -m http.server 8377
```

然后访问 <http://localhost:8377>。

## 高阶版视图(2.5D · three.js)

角色图谱、宇宙链路、时间线都提供「✨ 切换高阶版」:

- **角色星系图**:俯视倾斜的星盘,角色为发光星体、阵营为星云、关系为弧形光轨;拖拽旋转、Shift+拖拽平移、滚轮缩放、悬停聚焦。
- **立体地铁**:9 条故事线分层悬浮,站点竖井表示换乘;锁定线路后升亮并出现粒子流、顺序号与「下一站」光柱。
- **年代长廊**:沿透视道路前行的海报画廊,三列立牌、阶段色带铺地、今日金门;滚轮即时间前进。

扁平版与高阶版随时切换(偏好会记住),three.js 仅在打开高阶版时加载,扁平版依旧零依赖。

## 战报分享卡 & 3D 实验室

- 指挥中心 / 我的档案的「📸 生成我的战报」:用 Canvas 生成一张 1080×1350 的进度海报(完成度、宝石、路线、最近看完、成就),可保存或复制到剪贴板。
- 「🪐 3D 宝石展示台」:基于 three.js(本地 `vendor/three.min.js`,仅打开时加载)的无限宝石 3D 场景,点亮的宝石会发光,点击宝石跳转对应作品。

## 在线部署(GitHub Pages)

已登录 GitHub CLI 后执行:

```bash
bash tools/deploy.sh
```

脚本会创建公开仓库、推送并开启 Pages,1-2 分钟后即可通过 `https://<用户名>.github.io/MarvelSystem/` 访问(PWA、海报、本地存档均正常工作)。之后更新只需 `git push`。

## 观后解读(看完才解锁)

约 50 部作品配有「观后解读」:彩蛋逐条解析、伏笔追踪(这部埋的梗在哪部开花)、幕后冷知识。**未打卡时只显示锁定预告,看完打卡后解锁**——先看片,再来对答案。

## 观影状态与剧透保护

- 每部作品支持四种状态:**🤍 想看 / ▶ 在看 / ✓ 看过 / 🚫 弃了**;剧集可**按集打卡**,看到最后一集自动标记「看过」。
- 顶栏的「🙈 剧透保护」开启后,未看作品的剧情简介与看点会被模糊遮罩,点击可临时显示。
- 每一次打卡都会计入「我的档案」的半年热力图与连击统计。

## 手机使用(PWA)

用本地服务方式打开后(手机与电脑同一 Wi-Fi,访问 `http://<电脑IP>:8377`),在浏览器菜单选择**「添加到主屏幕」**即可作为独立 App 使用,支持离线打开(海报在看过一次后也会离线缓存)。

## 维护脚本

```bash
node tools/fetch-posters.mjs
```

从英文维基百科重新抓取海报(新作品上映后运行,需在 `tools/fetch-posters.mjs` 里补条目名);`node tools/make-icons.mjs` 重新生成 App 图标。

## 彩蛋

- 看完六部关键作品集齐无限宝石后,指挥中心会出现一个金色按钮。按下去会发生什么,漫威粉都懂。
- 每次打卡会随机弹出一句经典台词。
- 搜索框支持角色名(试试搜「洛基」)。

## 数据说明

- 收录范围:MCU 全部电影/剧集/特别篇(至 2026 年中已公布档期),以及雷米蜘蛛侠、超凡蜘蛛侠、X 战警、死侍、毒液、网飞夜魔侠、蜘蛛侠:平行宇宙等前代/关联作品。
- 未上映作品(《蜘蛛侠:崭新的一天》《复联:毁灭日》《复联:秘密战争》)的档期与内容以官方最新公布为准。
- 作品资料在 `js/data.js` 中,按同样的字段格式添加新作品即可扩展;路线与成就在 `js/routes.js`。
- 清除浏览器数据会清空进度,请先在「我的档案 → 数据管理」导出存档。

本项目仅供个人学习交流使用。
